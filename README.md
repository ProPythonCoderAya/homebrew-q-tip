# ProPythonCoderAya Q-tip

## How do I install these formulae?

`brew install propythoncoderaya/q-tip/<formula>`

Or `brew tap propythoncoderaya/q-tip` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "propythoncoderaya/q-tip"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
